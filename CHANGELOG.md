# Changelog

## [0.1.0] - 2026-11-02

- Native macOS menu-bar utility for macOS 26 Tahoe and later.
- Escalating amber, orange, and red edge glows at 3%, 2%, and 1% battery.
- Click-through overlays with transparent centers across connected displays.
- Timed previews, optional steady glow, and Reduce Motion support.
- Opt-in launch at login.
- Swift tests, GUI self-check, local/universal build and packaging scripts.
- Sandboxed Xcode target, privacy manifest, original icons, and archive tooling.
- Local Developer ID signing, temporary certificate keychains, Apple
  notarization, and verified universal DMGs with an Applications shortcut.
- Explicit GitHub publication with checksums, source provenance, dated release
  notes, and passing-CI guards. Manual CI release builds use GitHub Secrets.
